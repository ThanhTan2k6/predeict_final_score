# Predict Final Score - UIT

Ứng dụng dự đoán điểm cuối kỳ dựa trên điểm giữa kỳ bằng thuật toán **Linear Regression**.

## Demo
[https://predeict-final-score.onrender.com/](https://predeict-final-score.onrender.com/)

## Cấu trúc
- **Backend:** Flask (Python) xử lý train model và API dự đoán.
- **Frontend:** HTML/CSS/JS giao diện đơn giản.
- **Dataset:** Nạp sẵn file `TRAIN2.xlsx` để học quy luật.

## Local Setup
1. `pip install -r backend/requirements.txt`
2. `python backend/app.py`
3. Truy cập `http://127.0.0.1:5000`
